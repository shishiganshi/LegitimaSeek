 LegitimaSeek 🔍

 Introduction
LegitimaSeek is a real-time fact-checking and intelligence verification web platform designed with an editorial brutalist aesthetic. It serves as an instant verification terminal for claims, common hoaxes, and complex economic or budgetary inquiries.

 The Purpose of This Project
The primary purpose of LegitimaSeek is to combat misinformation and provide users with rapid, transparent, and data-driven insights. Whether you are verifying viral myths, calculating real-world living costs in the Philippines (such as testing budget sufficiency), or tracking live global multi-sector news, LegitimaSeek delivers structured empirical metrics, visual bar charts, and reliable context vectors without relying on costly paid backend servers.

 Tools Used
   HTML5 & CSS3: Custom editorial brutalist design system featuring a semantic dark mode toggle, dot-matrix background styling, and dynamic CSS bar charts.
   JavaScript (ES6+): Asynchronous API handling, custom query parsing, and a dynamic financial/budget calculation engine.
   APIs & Data Feeds: 
       Keyless AI Text & JSON Generation (`Pollinations.ai` / Hybrid Heuristics)
       Wikipedia REST & Search APIs
       Coinbase Crypto & Reddit Multi-Sector News Feeds
   Deployment: GitHub Pages (`shishiganshi.github.io/LegitimaSeek`)

 How to Use It
1. Fact-Checking / Claim Verification: Type any claim, myth, or financial question into the search box (e.g., "Is 2000 PHP enough for a week in the Philippines?" or "Do humans only use 10% of their brain?") and hit VERIFY.
2. Multi-Sector Intelligence Stream: Browse live headlines across Crypto, Stocks, Philippine Government/News, Sports, and Science using the sector filter tabs.
3. Training Module (Spot the Hoax): Test your disinformation radar by playing the rapid-fire mini-game.
4. Theme Switcher: Click the 🌓 icon in the top right header to toggle between light and dark brutalist terminal modes.
